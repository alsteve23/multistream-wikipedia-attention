Midterm — Hierarchical Time Series Visualization with MultiStream
Objective
Read the MultiStream paper and select a dataset suitable for hierarchical time-series visualization using MultiStream.

MultiStream — Paper and Visualization System

Requirements
Read and understand the MultiStream paper, particularly its requirements and design approach.
Select an appropriate multiple time-series dataset.
Define a clear use case / analytical question.
Create a visualization of this dataset similar to multistream (Hierarchical Time Series) using D3JS
Generate the hierarchy algorithmically from the time series using a clustering approach.
The hierarchy must contain at least 3 levels.
Deeper hierarchies and branches with different depths are encouraged when meaningful.
Generate the final .json file and verify that it works correctly in MultiStream.
Submission
Moodle — MultiStream dataset (.json)

Upload the final .json file used and successfully tested in MultiStream.

Course WhatsApp group — Video link (maximum 3 minutes)

Share a link to your video in the course WhatsApp group. The video may be hosted on YouTube, Google Drive, OneDrive, Vimeo, or any other platform. The link must be accessible without requesting additional permission.

The video must show:

the dataset running in MultiStream and your own visualization;
what the time series represent;
the use case / analytical question;
the resulting hierarchical structure;
navigation through different branches and hierarchy levels;
changes in granularity;
at least one meaningful temporal pattern or insight identified using MultiStream.
